# Ripple Code Demo

Non-system-lock Android interaction demo inspired by old Galaxy ripple unlock visuals.

- Tap any positions in any count.
- Finish input with one sufficiently long swipe in **any direction**.
- First sequence is stored only in memory as a demo code.
- Repeat the same hidden 5x8 logical zones in the same order, then swipe, to get MATCH.
- Swipe direction is never part of the comparison.
- No lock-screen APIs, device-admin APIs, biometrics, storage, network, or permissions are used.
